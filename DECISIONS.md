## Added later
- D10: ffmpeg is optional and never bundled or committed. The app looks for a user-installed copy and enables extra pairs only if it is found.
- D11: Untrusted HTML is rebuilt from an allowlist (attribute-free tags, no styles, images dropped) before WebKit sees it. Reason: HTML import runs WebKit and could fetch remote content. No fetch was reproduced on this macOS, so this is defense in depth.
- D12: Archive extraction lists entries first and refuses `..` or absolute paths, then extracts with bsdtar. Reason: zip-slip. Names go to zip and tar as `./name`; ffmpeg gets a forced demuxer and `-protocol_whitelist file`.
- D13: Copy Path single-quotes anything outside `A-Za-z0-9_./-` and puts multiple paths on one line. Reason: pasting must never run a path or inject a command.
- D14: Wheel ring switching waits about 180 ms before replacing the outer ring. Reason: crossing other wedges on the way to a far-side format must not close the ring.
- D15: Gzip names keep the original extension (`note.txt.gz`). Reason: matches the real tool and lets extraction restore the name.
- D16: Video to WAV is not offered (only M4A audio). Reason: AVFoundation exports audio-only to M4A; WAV would need a temp file outside the output folder.
- D17: Bundle id `dev.kiln.Kiln`; hardened runtime on; Apple Events entitlement for reading the Finder selection. No sandbox.
- D18: The Finder selection is read as an AppleScript list, item by item, and every path must exist. Reason: file names can contain newlines, and splitting text on them let one name become two paths (parsing is unit-tested).
- D19: Sound feedback defaults off and haptics on (revisits U17: silence is still the default, but sound is now an option, using system sounds only).
- D20: Lossy image outputs (JPG, HEIC, AVIF) default to quality 0.75 ("Balanced"). "Show Desktop results in Finder" became "Show finished files in Finder" for all results, off by default.
- D21: Settings are applied at job start. A job already running keeps the options it started with.
- D22: An output name counts as taken if anything is there, a dangling symlink included, and names are claimed across all running jobs. Reason: a link beside the input would otherwise be written through, and two same-name files dropped together would overwrite each other. Both are tested.
- D23: Archive extraction checks entry names on bytes before extracting, and relies on bsdtar refusing links and `..` paths. The quarantine flag of a downloaded archive is carried onto the extracted files by macOS tar (tested), so Gatekeeper still applies.
- D24: Copy Path writes any name containing control characters as `$'...'` with `\xHH` escapes, so pasting can never feed the terminal raw escape sequences.
- D25: Many files dropped at once all start together; there is no queue. Size caps look at the file on disk, not its expanded size. Both are accepted limits for a personal tool and are listed in the README.
